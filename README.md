# GitHub Actions Docs

A short documentation site for GitHub Actions, built with Thally.

Live site: https://github-actions-guide.thally.app/

## What is inside

- **Introduction:** what GitHub Actions is and who the site is for
- **Quickstart:** create and run your first workflow
- **Guide:** run tests on every push, with troubleshooting
- **Article:** how I built this site with Thally

## Repository layout

- `src/content` holds the pages
- `docs.json` controls the navigation
- `src/data/site.ts` holds the site settings
