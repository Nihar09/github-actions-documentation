## What is GitHub Actions?

GitHub Actions lets you automate tasks in your repository. You write the steps in a YAML file, and GitHub runs them when something happens, like a push or a pull request. Most people use it to run tests, build code, and deploy.

## Who is this for?

This guide is for developers who are new to GitHub Actions. You should know basic Git and have a GitHub repository to practice in. No other setup is needed.
