title: Quickstart
description: Create and run your first GitHub Actions workflow in a few minutes.
---

In this quickstart, you will create a workflow that prints a message every time you push to your repository. It is a small example, but it covers the full cycle: write a workflow, push it, and see it run.

## Before you begin

You need a GitHub repository where you can push code. A new, empty repository works fine.

## Create the workflow

1. In your repository, create a folder named `.github/workflows`.
2. Inside it, create a file named `hello.yml`.
3. Add this content:

```yaml
name: Hello Workflow

on: push

jobs:
  hello:
    runs-on: ubuntu-latest
    steps:
      - name: Say hello
        run: echo "Hello from GitHub Actions"
```

Here is what each part does:

- `on: push` tells GitHub to run the workflow on every push.
- `runs-on` picks the machine that runs your job.
- `steps` lists the commands to run. Here, there is just one.

## Run it

Commit the file and push it to GitHub. The push starts the workflow.

## Check the result

1. Open your repository on GitHub and click the **Actions** tab.
2. Click the latest run in the list. GitHub names it after your commit message, for example **Create hello.yml**.
3. Click the **hello** job, then expand the **Say hello** step.

You should see `Hello from GitHub Actions` in the log, and a green check mark next to the run.

## If nothing runs

Check that the file is inside `.github/workflows` and that its name ends in `.yml`. If the run shows a red mark, open it and read the error. The next guide covers common problems in more detail.
